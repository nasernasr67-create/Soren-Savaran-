# سورن سوار | Soren Savar

## فارسی
۱. همه فایل‌ها را مستقیم (بدون پوشه) روی شاخه main آپلود کنید.
۲. پوشه `.github` داخل همین زیپ هست و حتماً باید آپلود شود (با GitHub Desktop یا git).
۳. Settings ← Actions ← General ← Workflow permissions ← Read and write permissions.
۴. تب Actions ← Build APK. بعد از پایان، APK در Releases است.

## English
1. Upload all files directly (no folders) to the main branch.
2. The `.github` folder is included in this zip and must be uploaded (use GitHub Desktop or git).
3. Settings → Actions → General → Workflow permissions → Read and write permissions.
4. Actions tab → Build APK. When done, the APK is under Releases.
